# Under a Sky Full of Stars

A simple HTML and CSS project featuring a peaceful night-sky camping scene. The page uses a background image of mountains, stars, and a glowing tent, with centered text to create a calm and atmospheric design.

## Technologies
- HTML5
- CSS3

## Features
- Full-screen background image
- Responsive viewport setup
- Centered typography
- Simple, minimal design

## Project Files
- `Assignment 1.html` — Main webpage
- `Capture.PNG` — Background image

## How to Run
Open `Assignment 1.html` in any modern web browser.
